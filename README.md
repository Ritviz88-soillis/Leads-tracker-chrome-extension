# Leads Tracker Chrome Extension

A Chrome browser extension for tracking and managing sales leads. This extension helps users save, organize, and manage lead information directly from their browser.

## Features
- Save leads with one click
- Store lead information locally
- Organize and manage leads
- Browser extension functionality

## Technologies
- JavaScript
- Chrome Extension API
- HTML/CSS

## Purpose
Streamline lead management for sales and business development professionals.

## Installation
1. Clone or download the repository
2. Open Chrome and navigate to `chrome://extensions/`
3. Enable "Developer mode"
4. Click "Load unpacked" and select the extension folder
